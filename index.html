Security & provenance

ClamAV + 5 engines

Every archive is scanned by ClamAV and four additional engines before release. Zero threats reported on this build.

AES-256 end-to-end

Transfer is protected with AES-256 encryption end-to-end. Nothing touches disk in plaintext during transit.

SLSA level 3

The pipeline satisfies SLSA level 3: hermetic builds, signed provenance, source-code integrity checks.

No installer

Unzip the archive and launch Release_Launcher.exe — no setup wizard, no registry entries, no admin required.

No telemetry

Nothing calls home. The binary runs fully offline once the archive is extracted.

Refreshed every 48h

A fresh build is published every two days, so you always land on the latest verified version.

Secure delivery pipeline

Repository clone & hash validation

Sources are fetched from the pinned commit and the tree hash is validated against the signed manifest.

Deep static analysis (SAST + secrets)

SAST rules run over the full codebase, with secret-scanning to make sure no credentials leaked.

Dependency vulnerability audit (SBOM)

A full SBOM is produced and cross-checked against known-CVE feeds before packaging.

Code signing & notarization

Artifacts are signed and provenance is attached; the download button will start once the token is issued.
